# Support

Need help with moldui?

- **Bugs:** open a [bug report](https://github.com/Manavarya09/moldui/issues/new?template=bug_report.yml).
- **Feature requests:** open a [feature request](https://github.com/Manavarya09/moldui/issues/new?template=feature_request.yml).
- **Security issues:** see [SECURITY.md](SECURITY.md) — please report privately.
- **Questions:** start a [Discussion](https://github.com/Manavarya09/moldui/discussions).

We aim to respond to issues within 5 business days. PRs welcome!
